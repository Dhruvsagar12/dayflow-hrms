Project Title:
Dayflow - Human Resource Management System 

About the Project:
Dayflow Human Resource Management System is designed to manage HR operations efficiently. It enables tracking, updating, and analyzing employee information that is their professional details. The system handles leave requests, approval workflows for admins, and employee attendance. It also allows employees to input and update their own profile information.

Key Features:
Login / Sign-up functionality
Employee Dashboard
Payroll Summary
Leave Request Management
Admin Approval Workflow
Attendance Tracking

Technologies used:

Firebass as Bass
